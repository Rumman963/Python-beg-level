# Day 2: Notes                                 
                                               
                                               
- `range(a, b)` stops before `b`, so use `range
(1, n + 1)` to include `n`                     
- `break` exits the loop; `continue` skips to  
the next round                                 
- `% 10` gets the last digit, `// 10` removes  
it (reverse, digit sum, Armstrong)             
- For primes, check divisors only while `i * i 
<= n`                                          
- Keep variables inside the function; avoid    
`global`
